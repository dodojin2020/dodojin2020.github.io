# 이유진 연구자 홈페이지 (GitHub Pages)

HTML과 CSS만으로 만든 정적 사이트입니다. 이 저장소에 파일을 올리면 `https://dodojin2020.github.io` 에 반영됩니다.

## 내용 고치는 법

1. 저장소에서 고칠 파일(예: `research.html`)을 누릅니다.
2. 오른쪽 위 연필 모양 아이콘을 눌러 글자를 고칩니다.
3. 초록색 Commit changes 버튼을 누르면 1~2분 뒤 홈페이지에 반영됩니다.

## 구성

- `index.html` 첫 화면, `about.html` CV, `research.html` 연구, `talks.html` 발표, `writing.html` 글 목록, `media.html` 미디어
- `posts/` 개별 글. `posts/hello.html`을 복사해 새 글을 만들고, `writing.html`에 한 줄을 추가합니다.
- `assets/style.css` 색과 글꼴. 맨 위 `:root` 값만 바꿔도 분위기가 달라집니다.
